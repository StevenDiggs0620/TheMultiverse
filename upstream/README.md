# The Universe

**The Universe** is a sleek, customizable web portal for playing browser games, watching movies, listening to music, chatting, and using web tools all in one place.

*Made by **tasdiam**.*

## What You Can Do

### 🎮 Play Games
* **Browse & Search:** Quickly search through the entire game library by name or description.
* **Custom Views:** Sort games alphabetically or by catalog order, and adjust the grid size from compact to extra large.
* **Flexible Game Window:** Play games inside a clean framed window with quick fullscreen, reload, and close buttons, or switch to full-page mode in settings.

### 🧭 Built-In Tabs
Switch easily between Games and other built-in tools from the side navigation bar:
* **Movies**
* **Music**
* **Chat**
* **AI**
* **Tas Proxy**

### 🎨 Make It Yours
* **Themes:** Choose from built-in themes (*Purple*, *Midnight*, *Dark*, and *Light*) or design and save your own custom color theme using the live theme maker.
* **Custom Wallpapers:** Set any image link or upload a picture from your device to use as your background.

### 🔒 Privacy & Quick Controls
* **Tab Cloak:** Disguise the browser tab's title and icon using presets like *Document*, *Classes*, *Calculator*, or *Notes*, or enter your own.
* **Panic Key:** Set a custom keyboard shortcut to instantly jump to a safe website from anywhere on the site, even while playing a game.
* **`about:blank` Mode:** Open the site inside an `about:blank` tab manually or automatically whenever you visit.

## Keyboard Shortcuts
* **`F`** — Toggle fullscreen while in a game
* **`Esc`** — Exit fullscreen or close the current game
* **Custom Panic Key** — Instantly redirect to your chosen safe site
