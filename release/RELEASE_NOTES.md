# The Universe full final release — prerelease notes

This is a packaging release of The Universe from TheUniverses commit
`8c05c3fc83bad91313c48f39830d47b2db01e767`. The portal files are included as
an unchanged upstream snapshot. The repository remains named The Multiverse.

## Which files to use

- **Recommended: `.html` or `.htm`.** These open the portal in a browser frame
  and are expected to work in a current browser with internet access.
- **`.svg`:** browser launcher using SVG `foreignObject`; it works only where the
  browser permits that feature and external frames. Support varies.
- **`.xhtml` and `.xht`:** XHTML launchers; browser handling varies.
- **`.mht` and `.mhtml`:** archived launcher pages; browser support and remote
  frame behavior vary.
- **`.zip`:** the combined package. Extract it and open `The-Universe.html`;
  the ZIP itself does not auto-launch. It contains `Original Universe/` and the
  release files side by side. Both upstream filenames that differ only by case
  are preserved inside the ZIP; some case-insensitive drives may overwrite one
  when extracting the folder.
- **`.xml`:** XHTML content in an XML file; some viewers display source instead
  of rendering it.
- **`.webarchive`:** Safari WebArchive launcher attempt; external page loading
  depends on Safari and system settings.
- **`.maff`:** Mozilla Archive Format attempt; requires compatible archive
  software or an extension and may not open in a current browser by default.
- **`.hta`:** Windows HTML Application launcher; Windows-only and subject to
  local security policy.
- **`.pdf`, `.docx`, `.rtf`, `.odt`, `.pptx`, and `.odp`:** these provide a
  clickable link to open the portal in a browser. They do not run the portal
  inside the document or presentation. PDF viewers may warn before opening the
  link.
- **`.epub`:** includes an XHTML launcher attempt and link; ebook readers often
  restrict external frames and network access.
- **`.doc` and `.ppt`:** the old binary Office formats are not generated by the
  dependency-free builder. Use `.docx` or `.pptx` instead.

The portal and many of its games/services require an internet connection. Games
and services may have their own availability and browser requirements.
